## penguins dataset description

The `penguins` dataset contains information on three penguin
species:Adelie, Chinstrap, Gentoo. The penguins were observed on Biscoe,
Dream, Torgersen islands. Important variables include `species`,
`island`, `bill_length_mm`,`bill_depth_mm`,`flipper_length_mm`,
`body_mass_g`, `sex`, and `year`.

The dataset has 344 observations and 8 variables. The mean flipper
length is 200.92mm.

## penguins scatterplot

``` r
penguins_scatterplot = ggplot(
  penguins,
  aes(
    x = bill_length_mm,
    y = flipper_length_mm,
    color = species
  )
) + 
  geom_point(na.rm = TRUE)
```
