## Penguins dataset description

The `penguins` dataset contains information on three penguin species:
Adelie, Chinstrap, Gentoo. The penguins were observed on Biscoe, Dream,
Torgersen islands. Important variables include `species`, `island`,
`bill_length_mm`, `bill_depth_mm`, `flipper_length_mm`, `body_mass_g`,
`sex`, and `year`.

The dataset has 344 observations and 8 variables. The mean flipper
length is 200.92 mm.

## Dataframe

set.seed(1)

problem2_df = tibble(

### Description for variable means

The mean of `norm_samp` can be calculated because it is a numeric
variable.

For `norm_samp_pos`, R treats TRUE as 1 and FALSE as 0, so

$$\text{mean} = \frac{\text{number of TRUE values}}{10}$$

which is the proportion of observations for which `norm_samp > 0` is
TRUE.

For `vec_char` and `vec_factor`, the mean is not defined directly
because these variables are categorical rather than numeric. Therefore,
R returns NA with a warning when attempting to calculate their means.

## Numeric conversion

``` r
as.numeric(pull(problem2_df, norm_samp_pos))
as.numeric(pull(problem2_df, vec_char))
as.numeric(pull(problem2_df, vec_factor))
```

### Description for numeric conversion

For `norm_samp_pos`, converting the logical values to numeric gives

$$\text{TRUE} \rightarrow 1,
\qquad
\text{FALSE} \rightarrow 0.$$

This explains why the mean of `norm_samp_pos` can be calculated.

For `vec_char`, converting to numeric produces NA values because the
character strings do not represent numbers.

For `vec_factor`, converting to numeric produces integer codes for the
factor levels. These values are category codes rather than meaningful
numerical measurements.

Therefore, coercion helps explain why the mean can be calculated for a
logical variable, but not directly for character or factor variables.
